# 模板依赖与行为说明

## 当前模板

本 PR 新增的模板均为纯 Markdown / YAML 文本。

| 模板类别 | 插件依赖 | 网络/API | 脚本执行 | 文件行为 |
|---|---|---|---|---|
| Basic | 无强制依赖；可用 Obsidian 核心 Templates 插件插入 | 无 | 无 | 用户主动插入时创建笔记内容 |
| Research | 无强制依赖；可用核心 Templates 插件插入 | 无 | 无 | 用户主动插入时创建笔记内容 |
| Trading | 无强制依赖；可用核心 Templates 插件插入 | 无 | 无 | 用户主动插入时创建笔记内容 |
| AI Agent | 无强制依赖；Agent 是否能读写 Vault 取决于用户自己的工具配置 | 无 | 模板本身不执行 | 用户/Agent 按外部授权流程读写文件 |

## 安全边界

- 模板文件自身不包含 JavaScript、Shell、Python 或自动化命令。
- 模板不会自行运行，也不会自行修改 Vault。
- 用户将模板交给具有文件写入权限的 Agent 使用时，Agent 的行为由该 Agent 的权限和用户指令决定，不由模板保证。
- 不在模板中放置 API Token、密码、私钥或其他凭据。
- 使用者应检查日期占位符、属性字段和模板目录设置，避免与已有工作流冲突。

## 后续新增模板的准入要求

每个新模板都应记录：用途、来源、许可、依赖插件、是否执行脚本、是否联网、是否读写/覆盖文件，以及测试结果。
