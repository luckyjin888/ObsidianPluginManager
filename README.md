# ObsidianPluginManager

一个以安全、透明和用户确认优先为原则的 Obsidian 管理工具项目。

**当前版本：** 0.3.0  
**当前实际支持平台：** macOS  
**许可证：** GNU GPL-3.0-only

> 重要：项目名称和长期目标包含跨平台管理，但当前发布版本只实现 macOS 环境检查。Windows 和 Linux 尚未实现，不应视为已支持。

## 当前功能

- 检查当前操作系统。
- 在常见位置查找 Obsidian。
- 读取 Obsidian 应用版本，并检查是否达到 CLI 所需的最低版本号。
- 检查应用内置 CLI 文件是否存在且可执行。
- 检查终端是否能找到 `obsidian` 命令。
- 在用户明确同意后，运行 `obsidian version` 做基本运行检查。Obsidian 未运行时，该命令可能启动应用。
- 由用户输入 Vault 路径，不写死开发者的个人路径。
- 列出 Vault 中的社区插件目录。

## 当前不做什么

此版本不会：

- 自动安装、更新、卸载、启用或禁用插件。
- 自动注册 CLI、创建系统链接或修改 PATH。
- 调用 `sudo` 或申请管理员权限。
- 修改 Vault、插件文件或 Obsidian 设置。
- 判断插件是否安全、可信或已启用。
- 声称支持 Windows 或 Linux。

## 使用方法（macOS）

1. 安装 Obsidian。
2. 如果要使用 CLI，请按照 [Obsidian 官方 CLI 文档](https://obsidian.md/help/cli) 启用并注册 CLI。
3. 下载本仓库。
4. 在终端进入脚本所在目录。
5. 运行：

```bash
chmod +x obsidian_manager.sh
./obsidian_manager.sh
```

脚本会要求你输入 Vault 文件夹路径。可以输入绝对路径，也可以使用 `~/...`。

## 安全设计原则

本项目遵循：

1. **先检查，后操作**：默认只读；检查与修改分开。
2. **最小权限**：不因方便而要求管理员权限。
3. **明确同意**：任何会改变文件、系统设置、权限或隐私状态的操作，都必须先说明并获得用户明确批准。
4. **可追溯**：重要操作应说明目标、影响、风险和验证方法。
5. **不隐藏风险**：拒绝或取消授权时，不得继续执行相应操作。
6. **双版本说明**：所有操作说明必须同时提供「标准专业版」和「10岁儿童比喻版」，两者必须描述同一操作、权限、影响与风险。

详细规则见 [SECURITY.md](SECURITY.md)。
